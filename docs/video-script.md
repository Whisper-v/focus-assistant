## 二、分镜脚本

### 场景 0 · 片头 Hook（0:00–0:08）

- **画面**：黑场淡入 → 深色桌面，右下角一盆安静的小种子（应用待机态实拍）；光标缓缓靠近它。
- **字幕**：🌱 专注助手 Focus Assistant —— 住在你桌角的专注小助手
- **旁白**：你有没有想过，专注这件事，也可以有人陪着你一起完成？

---

### 场景 1 · 初见：它叫露（0:08–0:32）

- **画面**：启动器搜索“专注助手”→ 打开；无边框毛玻璃小窗浮现，种子呼吸起伏（实拍特写）。
- **字幕**：DTK6 + Qt6 原生应用 · 纯矢量自绘，无外部素材
- **旁白**：它叫露，是一棵住在你桌面角落的小植物。打开专注助手，把种子交给我，剩下的就交给时间。
- **演示要点**：鼠标在露上悬停、轻晃，让呼吸/微动画自然呈现。

---

### 场景 2 · 开始一段专注（0:32–0:58）

- **画面**：双击露 → 状态变为“守护中”，倒计时开始，露变认真脸（可贴汗滴特写）；随后在设置中勾选“联动系统护眼模式”再开启一轮，右下角叠加提示卡“护眼模式已联动”。
- **字幕**：双击露 = 开始 / 暂停 ｜ 可选开启：专注时联动系统护眼模式（D-Bus 真实联动）
- **旁白**：双击露，开始一段专注。它立刻换上认真脸陪你。你还可以在设置里打开“护眼联动”——专注一开始，系统会通过 deepin 的 D-Bus 接口**真实开启护眼色温**，结束自动还原；如果你本来就开着夜间色温，它也绝不会打扰。为了不影响桌面观感，这项联动默认关闭，按需开启。
- **演示要点**：此处可切屏展示系统“色温”生效前后的屏幕暖色差异；实拍不明显时，后期加“护眼模式联动中”角标卡。

---

### 场景 3 · 完成与休息（0:58–1:22）

- **画面**：倒计时归零 → 露撒花庆祝动画 + 桌面通知“专注完成！露伸了个懒腰：你太棒啦🌸”→ 自动进入休息，露闭眼打盹（zZz）→ 连续多轮后出现“长休息”提醒。
- **字幕**：专注完成 → 撒花庆祝 → 露打盹提醒你休息
- **旁白**：叮——专注完成。露会为你撒花庆祝，然后乖乖闭眼打盹，提醒你：休息，是为了更好地出发。连续专注好几轮之后，它还会主动劝你休个长一点的假。
- **演示要点**：庆祝/打盹动画建议用“快速完成”配置触发（见附录二），保证一次拍成。

---

### 场景 4 · 养成：把努力种成花（1:22–1:42）

- **画面**：快进/转场依次展示四个形态：沉睡的种子 → 青葱幼苗 → 含苞待放 → 花团锦簇；阶段栏“成长：xx · 再专注 N 次可成长”随之变化。
- **字幕**：种子 → 幼苗 → 含苞 → 盛放（按累计专注时长成长）
- **旁白**：而每一次专注，都会让露悄悄长大：从一颗沉睡的种子，到青葱幼苗、含苞待放，最后花团锦簇。它把你日复一日的坚持，变成桌面上看得见的风景。
- **演示要点**：四个形态可用演示数据切换展示（见附录二），转场用 0.3s 快切+轻微缩放，避免平淡。

---

### 场景 5 · 成长记录（1:42–1:58）

- **画面**：点击右下“统计”→ 成长记录弹窗：今日/累计专注/完成次数 + 最近 7 天柱状图。
- **字幕**：数据全本地保存，无联网、无隐私收集
- **旁白**：打开成长记录，今天的、累计的、最近七天的专注情况一目了然。所有数据只保存在你自己电脑上，不上传、不收集。

---

### 场景 6 · 低打扰的陪伴方式（1:58–2:18）

- **画面**：按住露把窗口拖到桌面另一角；点击关闭 → 窗口收起、托盘图标常驻；演示托盘右键菜单（开始/暂停、成长记录、退出）。
- **字幕**：可拖动 · 关窗收进托盘 · 托盘随时开始/暂停
- **旁白**：露是可以搬家的——按住它，放到你喜欢的任何角落。即使关掉窗口，它也会安静地待在系统托盘里继续守护。不打扰，才是最长情的陪伴。

---

### 场景 7 · 背后：deepin Skills 驱动的开发（2:18–2:40）

- **画面**：快切工程结构（src/ 树）、CMake 代码、护眼色温 D-Bus 探测片段、AI 与 Skills 对话截图（1–2 张可放入此处或作为附件）、README 截图。
- **字幕**：基于 deepin Skills「dtk-development」开发 ｜ 依据权限边界主动取舍功能
- **旁白**：回到开发本身：整个作品都建立在 deepin Skills 生态之上。我用 dtk-development 技能拿到 DTK6 的标准工程模板和 D-Bus 规范；也正因为技能文档里写明了“第三方应用不能改写系统 DConfig 配置”的权限边界，我们主动放弃了一开始设想的“自动勿扰”，改用系统公开接口实现联动——把稳定、安全和可控放在第一位。
- **演示要点**：此段节奏加快，配代码/文档快闪，控制在 22 秒内。

---

### 场景 8 · 结尾（2:40–2:50）

- **画面**：回到盛放形态的露，微风轻摆、眨眼；画面下方浮现活动名 + 作品名。
- **字幕**：【deepin插件开发活动】专注助手 Focus Assistant ｜ 喜欢它就投它一票
- **旁白**：把每一次专注，都种成一朵花。专注助手——如果露有打动你，欢迎到 deepin 社区给我们投上一票，谢谢！

## 三、拍摄与剪辑建议

1. **录制工具**：OBS / Peek（gif 也可）均可；主窗口建议 1080p、60fps 录制动画会更顺滑。
2. **演示前重置状态**：`rm -rf ~/.config/focus-assistant`，保证从“沉睡的种子”开始，叙事完整。
3. **鼠标**：开“鼠标高亮/点击光圈”，方便观众看清交互。
4. **字幕节奏**：每句旁白 ≤ 22 字/行，避免长句；重点词（护眼联动、DTK6、成长、本地存储）用主题色强调。
5. **音乐**：音量压到人声的 -18dB 左右；结尾可留 1s 尾音渐弱。
6. **成品格式**：H.264 + AAC，≤ 100MB；同时保留一份 1 分钟“精华版”用于帖子预览图/短视频。

## 附录二：演示技巧（实拍加速方法）

- **快速触发“完成撒花 + 打盹”**：写入临时配置 `[prefs]` 的 `focusMin=0`（`~/.config/focus-assistant/focus-assistant.conf`），点“开始专注”即瞬间完成；拍完删除配置。
- **快速展示 4 个成长形态**：分别把 `[stats]` 的 `totalSeconds` 设为 0 / 900 / 3600 / 12000 后重启应用，逐段拍摄，剪辑中标注“时间流逝”。
- **护眼色温对比**：录一段开启前后屏幕同画面素材，剪辑左右分屏/前后对比，观感更直观。
